*PART 1 FIXES*

**PART 2 CHANGELOG**
- An external stylesheet (style.css) was created and linked to all five HTML pages.
- Base styles were established, including a CSS reset, default font family, colour scheme, and consistent margin/padding.
- Typography styles were applied using font-family, font-size, font-weight, line-height, and letter-spacing, with relative units (rem) for scalability.
- Layout structures were built using CSS Flexbox (for the header and forms) and CSS Grid (for the product listings and desktop sections).
- Visual styles were applied using color, background-color, border, and box-shadow, along with :hover, :focus, and :active pseudo-classes for interactive elements.
- Responsive design was implemented using media queries at tablet (768px) and desktop (1024px) breakpoints, with multi-column layouts that collapse to a single column on smaller screens.
- Relative units (rem, %) were used for font sizes, spacing, and widths to ensure responsiveness.
- Invalid HTML Fixed
- Redundant Markup Removed
- Navigation Improved
- Accessibility Enhanced
- Inline Styling Cleaned Up
